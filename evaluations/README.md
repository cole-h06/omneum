# External Evaluations

This directory contains permissioned technical evaluations of Omneum against external systems and workflows.

Each evaluation documents:

- the external system and evaluation boundary
- the Omneum version tested
- the provenance and dependency signals available
- the test procedure
- observed results
- known limitations or integration boundaries
- sanitized machine-readable output when available

Only results approved for public use are included here.

- [Bastra Recall — Omneum 1.0.3 local evaluation](bastra-recall/README.md):
  Daniel Nevoigt's external evaluation, with the original evaluator-supplied
  single-claim and multi-claim JSON artifacts and a detailed results record.

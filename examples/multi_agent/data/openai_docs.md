# GPT-5.6 Sol API Documentation

## Model Overview

GPT-5.6 Sol is OpenAI's next-generation frontier model with stronger capabilities in complex coding, science, cybersecurity, and professional knowledge work.

## Capabilities

GPT-5.6 Sol supports:

- Text input and output
- Image input
- Streaming responses
- Function calling
- Structured outputs
- Web search
- File search
- MCP tools

## API

The recommended endpoint for new applications is:

POST /v1/responses

## Context

- Context window: 1,050,000 tokens
- Maximum output: 128,000 tokens

## Reasoning

Supported reasoning effort levels:

- none
- low
- medium
- high
- xhigh
- max

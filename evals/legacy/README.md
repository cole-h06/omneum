# Legacy External Evaluations

Historical external evaluations of **Omneum 1.0.3's assertion-evaluation capabilities**. These reports document the observed results, failures, and integration limitations of that release.

- [Bastra Recall](bastra-recall/README.md) — synthetic agent-memory histories; original single-claim and multi-claim outputs.
- [Jawz](jawz/README.md) — macroeconomic data provenance with FRED lineage declared and undeclared.
- [SearchTS](searchts/README.md) — web retrieval provenance and source independence; original captures and reproduction files.

Original results, artifacts, and reproduction files are preserved unchanged. Jawz remains **README-only**: withheld per-source and pairwise artifacts are not published.

Context-control-plane benchmarks are maintained separately under [`benchmarks/`](../../benchmarks/README.md).

# Security Policy

## Supported Versions

Security fixes are made against the latest version of Omneum.

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |

## Reporting a Vulnerability

Please report suspected security vulnerabilities privately rather than through
a public GitHub issue.

You can do this by opening a
[GitHub Security Advisory](https://github.com/cole-h06/omneum/security/advisories/new).

Please include whatever is needed to reproduce the issue. Useful information
includes:

- Affected version or commit
- Affected component or source file
- Configuration required to reproduce the issue
- Steps to reproduce
- Proof-of-concept code, if applicable
- Expected impact

Avoid accessing data that does not belong to you or disrupting systems while
testing a vulnerability.

## Bug Bounties

Omneum is a small open-source project currently and doesn't have a paid bug bounty
program.

## Scope

Security reports may cover any part of Omneum, including the MCP server,
installer, daemon, VOPRF implementation, input handling, and persistence.
